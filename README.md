# Pflege Deutsch Trainer V2

医療・介護ドイツ語を練習するPWAです。

## V2の追加機能
- 登録単語の編集（日本語・ドイツ語・カテゴリー・メモ）
- 登録単語の削除（確認ダイアログ付き）
- 既存V1の単語・学習状況を同じLocalStorageから引き継ぎ
- PWA / オフライン対応

## GitHub Pages
1. GitHubリポジトリを開く
2. V2のファイルで既存ファイルを置き換える
3. Settings → Pages → `main` / `/(root)`
4. 公開URLを開く

※ V2への更新後、サービスワーカーの更新により古い画面がしばらく残る場合があります。スマホで古い画面が表示されたら、アプリを一度閉じて再度開くか、必要ならブラウザ側でページを再読み込みしてください。
