# Pflege Deutsch Trainer

医療・介護ドイツ語の学習用PWAです。

## できること

- フラッシュカード
- 日本語→ドイツ語クイズ
- ドイツ語音声の再生
- ブラウザ音声認識による簡易発音チェック
- 患者さんとの会話フレーズ
- 単語の追加・検索・カテゴリー分け
- お気に入り・習得状況
- JSONバックアップ／復元
- オフライン利用（PWA）

## データについて

単語と学習状況はブラウザのローカルストレージに保存します。サーバーには送信しません。
端末を変更する場合は「JSONを書き出す」でバックアップしてください。

## GitHub Pagesへの公開

1. GitHubでアカウントを作る。
2. 新しいRepository（例: `pflege-deutsch-lernapp`）を作る。
3. このフォルダの中身をRepositoryへアップロードする。
4. Repositoryの Settings → Pages から、Branch `main` / folder `/ (root)` を選んで公開する。
5. 発行されたURLをAndroid Chromeで開き、「ホーム画面に追加」または「アプリをインストール」を選ぶ。

## 注意

発音チェックはブラウザの音声認識結果を使った簡易判定です。実際の発音の正確さを医学的・言語学的に評価するものではありません。
